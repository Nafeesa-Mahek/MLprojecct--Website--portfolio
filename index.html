// Phase Architecture

Project Overview

Diabetes mellitus affects hundreds of millions globally. Hospital 30-day readmission rates are a critical quality indicator — the US Centers for Medicare & Medicaid Services financially penalizes hospitals with excessive rates. Our project builds a rigorous, end-to-end ML pipeline to predict which diabetic patients are most at risk of readmission, enabling targeted post-discharge interventions.

01 🔬
Data Loading & Inspection
Loaded the UCI Diabetes 130-US Hospitals dataset (101,766 encounters, 1999–2008). Identified missing values encoded as '?', inspected 49 features spanning demographics, clinical measurements, medication indicators, and ICD-9 diagnosis codes.
02 ⚙️
Preprocessing & EDA
Dropped high-missingness columns (weight ≈97%, medical_specialty ≈49%). Deduplicated to 71,515 unique patient records by keeping first encounters. Applied SMOTE exclusively to training data. One-hot encoded categoricals. Explored distributions, outliers, correlations.
03 🤖
Baseline Model Training
Trained and compared 6 classifiers: Logistic Regression, Decision Tree, Random Forest, Naïve Bayes, KNN, and XGBoost on SMOTE-augmented training data. Evaluated on original validation set using F1, Recall, AUC-ROC, and Balanced Accuracy.
04 🎯
Model Improvement
Applied RandomizedSearchCV hyperparameter tuning for XGBoost and Random Forest. Key: calibrated scale_pos_weight ≈10.36 to class imbalance ratio. Optimized decision threshold via precision-recall curve analysis. Compared Voting and Stacking ensemble classifiers.
05 📊
Held-Out Evaluation & Interpretability
Final evaluation on untouched test set (15%). Analyzed feature importance across 4 methods: SelectKBest, RF Importance, RFE, and PCA. Top predictors: num_medications, number_diagnoses, time_in_hospital. Documented limitations and future directions.
⚕ 📚
Literature Review
Reviewed 4 key studies on diabetes readmission prediction. Identified gaps: most models rely on retrospective EHR data, sensitive to missing values and class imbalance, limited generalizability. Motivated our rigorous preprocessing pipeline and evaluation approach.
// Problem & Dataset

The Challenge

Predicting 30-day readmission in diabetic patients is clinically critical but technically hard. Standard accuracy metrics are deceptive on imbalanced data — a model predicting "never readmitted" still achieves >91% accuracy while failing entirely on high-risk patients.

Our pipeline specifically addresses four core challenges that make this a difficult real-world ML problem:

  • ⚖️
    Severe Class Imbalance 91.4% non-readmitted vs 8.6% readmitted. Accuracy is useless — F1 and recall are primary metrics.
  • 🌐
    High-Dimensional Heterogeneous Features 49 features mixing numerical, categorical, sparse drug indicators, and ICD-9 codes.
  • 🔇
    Noisy, Incomplete Clinical Data Real-world EHR data with missing values, coding inconsistencies, and duplicate encounters.
  • 🔄
    Data Leakage Risk Repeated patient encounters require careful first-encounter deduplication to prevent leakage.

// Results & Conclusions

Key Findings

🏆
XGBoost Wins
Threshold-tuned XGBoost outperformed all 6 baseline classifiers on every minority-class metric. Calibrating scale_pos_weight to the class imbalance ratio (≈10.36) was critical.
F1: 0.38 Best model · Test set
📉
Accuracy is Misleading
Random Forest achieved 90% accuracy yet only 0.18 recall — missing over 80% of true readmissions. High accuracy on imbalanced data is not a meaningful metric.
RF: 90% Acc Only 0.18 Recall
⚡
Threshold Tuning Helps
Moving from the default 0.5 threshold to a precision-recall optimized threshold improved F1 by 3–5 percentage points with a meaningful recall boost — vital for clinical use.
+3–5 pts F1 improvement via tuning
🔑
Top Predictive Features
Consistent across all 4 feature selection methods: num_medications, number_diagnoses, time_in_hospital, num_lab_procedures, and insulin/metformin change flags.
4 Methods Consistent feature ranking
🧬
SMOTE Boosts Recall
Applying SMOTE only to the training set (≈91K samples post-oversampling) substantially improved recall across all models without introducing data leakage into validation or test.
~91K Training samples after SMOTE
🎯
AUC-ROC: 0.72
The final XGBoost model achieves AUC-ROC of 0.72 and balanced accuracy of 0.68, confirming it learns genuine readmission signals (MCC = 0.28) beyond majority-class dominance.
AUC: 0.72 Final held-out test set
